NetMeter

How much of your data plan is gone, from the menu bar.

A small network monitor for macOS: live rate, any time range, per-app usage, and progress against your monthly cap. It needs no root, no kernel extension and no Accessibility permission.

Install with Homebrew

brew tap omerdikyol/netmeter brew trust omerdikyol/netmeter brew install --cask netmeter
Download the .dmg Source on GitHub Version 0.1.1 · macOS 13+ · Apple silicon and Intel · signed and notarized

This is the app's real panel, running in your browser on made-up traffic. Try the ranges, drag across the graph, or open settings.

Why another one

Stats and iStat Menus already show network traffic. NetMeter differs in two ways.

It is built around a data cap. Set your plan's size and reset day, and the panel shows how much of it is gone and when it renews, with notifications as you cross the thresholds you picked.

It needs no privileges. It reads the same per-interface counters Activity Monitor does, and nettop for per-app numbers. History is a SQLite file on your Mac. There are no accounts and nothing is uploaded.

Other ways to install

Download the .dmg or .zip from Releases, open it, and drag NetMeter into Applications. Or build it from source with Rust 1.80 or newer:

git clone https://github.com/omerdikyol/netmeter
cd netmeter
cargo build --release
packaging/macos/bundle.sh
open dist/NetMeter.app

Left-click the menu bar icon for the panel, right-click for Settings and Quit. If you use a menu bar manager such as Ice or Bartender and the icon does not appear, move NetMeter to the always-visible section.

Good to know

NetMeter only counts while it is running, so totals cover that time and the panel says since when. Turn on launch at login to avoid gaps. Per-app numbers come from nettop and cover only what happened while the app was open.

It is macOS only for now. The core crate (sampling, storage, statistics) is platform-neutral; the panel's webview needs work on Linux and Windows has not been tried.
